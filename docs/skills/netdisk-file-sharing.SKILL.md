# 文件分享

当用户需要你交付一个文件，而不是只在聊天中展示内容时，按下面流程处理：

1. 使用 `file_write` 在本地创建文件。
2. 使用 `netdisk_upload` 上传该文件到网盘。
3. 将 `netdisk_upload` 返回的下载 URL 发给用户。
4. 明确提醒用户：下载链接 48 小时后过期。

## 安全规则

- 不要上传密钥、密码、token、私密配置、数据库文件或未经用户确认的本地文件。
- 如果文件可能包含隐私或敏感信息，上传前先向用户确认。
- 需要交付多个文件时，可以先分别用 `file_write` 创建所有文件，然后用 `netdisk_upload` 的 `paths` 参数一次上传多个文件；返回给用户的是一个网页列表链接，用户可在页面中逐个下载。
- 下载文件名应简洁清晰，能表达文件内容。
- 如果 `netdisk_upload` 失败，说明失败原因，并在可行时建议用户稍后重试。
